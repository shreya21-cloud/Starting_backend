# Backend Development Learning Repository

## 📘 Overview

This repository contains my **backend development learning and practice work**.
Here I am learning core backend concepts step by step using **Node.js**, **Express.js**, and **MongoDB** while implementing authentication, database operations, and server-side logic.

This is not a single project — it is a **collection of backend practice examples and concepts** that I have learned and implemented.

---

## 🛠️ Technologies Used

* **Node.js** – JavaScript runtime environment
* **Express.js** – Backend framework for building servers & APIs
* **MongoDB** – NoSQL database
* **Mongoose** – MongoDB ODM
* **bcrypt** – Password hashing and verification
* **Nodemon** – Development tool for auto restart
* **EJS (if used)** – Server-side templating
